📋 Task

Scenario: You are a system administrator and need to create a new user account for a developer joining your team.

Requirements:

  • Username: john_dev
  • User ID (UID): 2500
  • Home Directory: /home/john_dev
  • Shell: /bin/bash
  • Comment: Developer Account
  • Primary Group: developers (GID: 3000)
💡 Solution Steps: 1. Create the group first:
sudo groupadd -g 3000 developers

2. Create the user:
sudo useradd -u 2500 -g developers -d /home/john_dev -s /bin/bash -c "Developer Account" john_dev

3. Verify with:
id john_dev
getent passwd john_dev
